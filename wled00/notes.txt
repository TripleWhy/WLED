Certainly! To remove unused symbols during linking with **GCC**, follow these steps:

1. **Compile with Separate Sections**:
   - Compile your code using the following compiler flags:
     ```
     -fdata-sections -ffunction-sections
     ```
   - These flags will separate the code into distinct sections within the translation unit¹.

2. **Link with Optimization**:
   - When linking, use the following linker optimization flag:
     ```
     -Wl,--gc-sections
     ```
   - This instructs the linker to discard unreferenced sections, effectively removing unused functions and data¹.

Remember that building a call graph to accurately identify unused symbols can be challenging, especially for global, accurate call graphs. However, these steps should help optimize your executable size by removing unnecessary symbols. 🚀👍¹³
